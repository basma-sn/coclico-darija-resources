# Structure des fichiers CSV

Les exports de travail peuvent contenir notamment :

- `locuteur`
- `condition` (`EMPH` / `NEMPH`)
- `index_voyelle`
- `voyelle_annotee`
- `voyelle_analyse`
- `debut_voyelle`
- `fin_voyelle`
- `duree_voyelle`
- `temps_milieu`
- `F1_Hz`
- `F2_Hz`
- `consonnes_adjacentes`
- `positions`
- `contextes_bruts`
- `max_formant_Hz`
- `F1_final_Hz`
- `F2_final_Hz`
- `controle_final`

Les noms exacts peuvent évoluer entre les étapes de nettoyage et de contrôle manuel.
