# Pronunciation dictionaries

This directory contains two X-SAMPA pronunciation dictionaries developed for Moroccan Arabic:

- `dictionnaire_corrige_2844.dict`: manually reviewed core dictionary containing 2,844 entries.
- `dictionnaire_etendu_43253.dict`: extended dictionary containing 43,253 entries with broader lexical coverage and partial manual validation.

The dictionaries are intended for use with SPPAS.
